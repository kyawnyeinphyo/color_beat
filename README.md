# Beat Color Visualizer (စည်းချက်အလိုက် အရောင်ပြောင်း Visualizer)

သီချင်းထဲက Beat (စည်းချက်/ဘေ့စ်သံ) အတိုင်း Window တစ်ခုလုံး လှပတက်ကြွသော Neon မီးရောင်စုံများ အလိုအလျောက် ပြောင်းလဲပေးသည့် Python Desktop Application ဖြစ်ပါသည်။

---

## 🌟 အဓိက ပါဝင်သော Features များ

1. **Dual Audio Input**:
   - **🎤 Live Microphone Mode** - အခန်းတွင်း/စပီကာမှ ဖွင့်ထားသော မည်သည့်သီချင်းသံကိုမဆို မိုက်ခရိုဖုန်းမှတစ်ဆင့် ဖမ်းယူပြီး စည်းချက်အတိုင်း အရောင်ပြောင်းပေးခြင်း။
   - **🎵 Audio File Player** - မိမိဖွင့်လိုသော သီချင်းဖိုင် (`.mp3`, `.wav`, `.flac`, `.ogg`) ကို ရွေးချယ်ပြီး တိုက်ရိုက်ဖွင့်နိုင်ခြင်း။

2. **🎨 5 Visual Color Modes (မီးရောင်စုံ ၅ မျိုး)**:
   - **Solid Strobe (စတိတ်ရှိုး မီးရောင်စုံ ဖလက်ရှ်)**: စည်းချက်တိုင်းတွင် screen တစ်ခုလုံး အရောင်တောက်တောက်များ flash ပေးသည့် ပုံစံ။
   - **Radial Pulse (ဗဟို အလင်းလှိုင်း)**: ဗဟိုမှ အပြင်သို့ အရောင်လှိုင်းလုံးများ ပြန့်ကားထွက်သည့် ပုံစံ။
   - **Rainbow Wave (သက်တံရောင်စဉ်)**: သက်တံရောင်စဉ် လှိုင်းများ စည်းချက်နှင့်အညီ ရွေ့လျားပြောင်းလဲသည့် ပုံစံ။
   - **Cyberpunk Neon (ခရမ်းစိမ်းနီယွန်)**: Cyberpunk vibe ပန်းခရမ်းနှင့် အပြာစိမ်းရောင် နီယွန်မီးပုံစံ။
   - **Ambient Breathing (အေးဆေး အလင်းစုံ)**: အခန်းတွင်း ambient light ကဲ့သို့ အေးဆေးငြိမ့်ညောင်းစွာ အရောင်ပြောင်းသည့် ပုံစံ။

3. **⛶ Fullscreen Display**:
   - `F` သို့မဟုတ် `F11` (သို့) Double Click နှိပ်လိုက်ရုံဖြင့် မျက်နှာပြင်အပြည့် (Fullscreen) ကြည့်ရှုနိုင်ပါသည်။

4. **⚡ Real-time FFT & Adaptive Beat Detection**:
   - Bass (Kick drum / Sub-bass: 20Hz - 160Hz) စည်းချက်များကို တိကျစွာ ခွဲခြမ်းစိတ်ဖြာပြီး အလင်းပြောင်းလဲမှု အလိုအလျောက် တွက်ချက်ပေးပါသည်။

---

## 🚀 စတင်အသုံးပြုပုံ (How to Run)

Terminal ဖွင့်ပြီး အောက်ပါ command ဖြင့် စတင်အသုံးပြုနိုင်ပါသည်:

```bash
cd /Users/kyawnyeinphyo/Desktop/dev/color_beat
./run.sh
```

သို့မဟုတ် သီချင်းဖိုင် တိုက်ရိုက်ထည့်ဖွင့်လိုပါက:
```bash
./run.sh "/path/to/your_song.mp3"
```

## ⌨️ Shortcut Keys (ကီးဘုတ်ဖြတ်လမ်းများ)

| Key | လုပ်ဆောင်ချက် |
|---|---|
| `F` သို့မဟုတ် `F11` | Fullscreen ဖွင့်/ပိတ် |
| `Space` | Play / Pause ရပ်/ဖွင့် |
| `M` | Color Mode ပြောင်းခြင်း (Solid, Radial, Rainbow, Cyberpunk, Ambient) |
| `O` | သီချင်းဖိုင် အသစ်ရွေးချယ်ဖွင့်ခြင်း (Open Audio File) |
| `L` | Live Microphone သို့ ပြန်ပြောင်းခြင်း |
| `Up` / `Down` | Beat Sensitivity (အာရုံခံနိုင်စွမ်း အတိုး/အလျော့) |
| `H` | အပေါ်က Control Bar ဖျောက်/ပြ (mouse ရပ်ထားလျှင် ၃ စက္ကန့်အတွင်း အလိုအလျောက် ပုန်းသွားပါမည်) |
| `Esc` | Fullscreen မှ ထွက်ခြင်း (သို့မဟုတ် ပိတ်ခြင်း) |
